# Fiscal da Farmácia VR - Treinamento de Biossegurança e Inspeção Sanitária

Descrição: Aplicação web interativa 3D e VR estereoscópica desenvolvida para capacitação e fiscalização em boas práticas de laboratório, farmácia e biossegurança (normas ANVISA/NBR).

Tecnologias Utilizadas:

  • HTML5, CSS3 (Tailwind CSS)
  • JavaScript ES6+ Puro (Sem frameworks externos pesados)
  • Three.js (Renderização WebGL 3D / Panorama VR Estereoscópico)
  • DeviceOrientation API (Giroscópio para controle de cabeça Cardboard)
  • Web Audio API (Sintetizador de áudio procedural sem dependência de MP3)
  • LocalStorage API (Persistência local de registros e desempenho)

Como Executar no GitHub Pages:

  1. Faça upload deste arquivo index.html para a raiz do seu repositório no GitHub.
  2. Vá em Settings > Pages no GitHub.
  3. Selecione a branch main e salve. O site estará online via HTTPS.
  4. Acesse via navegador de smartphone iOS/Android com HTTPS para habilitar permissões de giroscópio.

Arquitetura Integrada do Projeto:

O projeto foi encapsulado utilizando módulos orientados a objetos em JS:

  • VRManager: Gerencia renderizador Split-Screen stereo e giroscópio.
  • AudioManager: Gera osciladores harmônicos para efeitos sonoros.
  • StorageManager: Controla o salvamento em LocalStorage.
  • GameEngine: Gerencia loop principal, colisão de mira (raycasting), temporizadores e pontuação.

Gire o Dispositivo

Para uma experiência imersiva no Google Cardboard, posicione seu smartphone na horizontal (Modo Paisagem).
